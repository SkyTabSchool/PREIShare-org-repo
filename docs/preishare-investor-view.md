# Who PREIshare is

PREIshare is a real-estate intelligence product that helps investors make intelligent decisions, and what a member should see is a clean, trustworthy dashboard where portfolio value, open deals, and profile details can be scanned in one place without hunting through cluttered pages.

## 1. Primary actors

- **Investor** — the member who uses the dashboard to scan portfolio value, open deals, and profile details.
- **Future admin** — a later operator who would manage members or listings. Out of scope for building in this shell sprint.

## 2. Investor goals

- Scan portfolio value.
- Open deals.
- View profile.

## 3. Must-have dashboard areas

- Home overview
- Portfolio
- Deals
- Profile

## 4. Success criteria

A stakeholder demo is successful when:

- The home overview shows portfolio value at a glance, with a clear path to deals and profile.
- Portfolio, deals, and profile each open on their own page from shared navigation, without hunting through cluttered screens.
- The same layout stays readable on a desktop window and a narrow phone-width window.
- Each area is a reusable screen in the dashboard shell, with placeholder content that is enough to scan the area.

## 5. Out of scope (shell-only sprint)

- Building future-admin screens or workflows.
- Sign-in, accounts, billing, and permissions.
- Live data, database storage, or real portfolio calculations.
- Creating, editing, or closing deals.
- Editing a real profile or saving member details.
- Search, notifications, and underwriting tools.
